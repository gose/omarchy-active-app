# Upstream

Active App began as a user-owned clone of `omarchy.active-window` from
[basecamp/omarchy](https://github.com/basecamp/omarchy), version `4.0.0-1`.

The standalone widget replaces the focused window title with desktop-entry
resolution, an application icon, and the application name. It also provides a
bounded label width, an icon-only vertical layout, and focused-app activation
on click.

The upstream license is preserved in `LICENSE.upstream`.
